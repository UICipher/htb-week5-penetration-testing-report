I have completed another practical milestone in my cybersecurity learning journey through the AstraQuantum Tech Summer of Cybersecurity 2026 program.

This week's work focused on penetration-testing methodology and professional security reporting in authorized Hack The Box Academy labs. I practiced service enumeration, web and TLS review, Linux security configuration checks, evidence collection, risk assessment, and writing realistic defensive recommendations.

The biggest lesson was that penetration testing is not only about finding a technical issue. It is also about staying within scope, validating observations carefully, protecting sensitive evidence, explaining business impact without exaggeration, and recommending fixes that can be retested.

I have documented the learning outcomes in a VAPT-style report and added a sanitized version of the project to GitHub. No credentials, flags, tokens, or unauthorized target information are included.
